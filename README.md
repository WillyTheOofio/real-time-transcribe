# AI Meeting Analysis System

An AI-based meeting analysis system that records a meeting, transcribes the conversation, identifies different speakers, extracts important keywords, summarizes the meeting, and provides feedback for each participant.

## Features

* Meeting audio recording
* Speech-to-text transcription using WhisperX
* Speaker diarization using PyAnnote
* Automatic keyword extraction
* Keyword descriptions
* Meeting summary
* Participant contribution analysis
* Individual feedback and improvement suggestions
* GPU/CUDA support when available
* Saves the analysis results to a text file

## System Workflow

```text
Meeting Audio
      ↓
Audio Recording
      ↓
WhisperX Transcription
      ↓
Speaker Diarization
      ↓
Diarized Transcript
      ↓
Keyword Extraction
      ↓
Meeting Summary
      ↓
Participant Feedback
      ↓
Saved Analysis Results
```

## Setup

The program requires Python and several machine-learning libraries.

A Hugging Face access token is also required for the speaker diarization model.

Create a `.env` file in the project directory:

```text
HUGGINGFACE_TOKEN=your_huggingface_token
```

The `.env` file should not be uploaded to GitHub.

## Running the Program

Run:

```bash
python test.py
```

The program will:

1. Record the meeting through the microphone.
2. Stop recording when Enter is pressed.
3. Transcribe the audio.
4. Identify speakers.
5. Extract important keywords.
6. Generate keyword descriptions.
7. Generate a meeting summary.
8. Analyze each participant's contribution.
9. Save the results to `meeting_analysis_result.txt`.

## Output

The program produces:

* A diarized transcript
* Meeting keywords
* Keyword descriptions
* Meeting summary
* Participant feedback

The final analysis is saved as:

```text
meeting_analysis_result.txt
```

## Notes

This project was developed as a prototype for analyzing meeting efficiency and participant contributions using AI.

The speaker labels generated by the diarization system identify different speakers, but they do not automatically know the real names of the participants.

The quality of transcription and speaker identification can depend on microphone quality, background noise, overlapping speech, and the number of speakers.
